# Автотесты для разных языков интерфейса

Тест проверяет, что на странице товара есть кнопка добавления в корзину.
Язык пользователя передаётся в Chrome из командной строки.

## Запуск

```bash
pip install -r requirements.txt
pytest --language=es test_items.py
```

Без параметра `--language` используется английский (`en`).
